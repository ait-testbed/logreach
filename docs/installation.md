# Installation

Requires Python >= 3.14.

## From PyPI

```bash
uv tool install logreach   # or: pipx install logreach  
logreach --help
```

## From source

```bash
git clone https://github.com/ait-testbed/logreach.git
cd logreach
uv run logreach --help
```

When running from source, prefix the `logreach` commands in these docs with `uv run`.
